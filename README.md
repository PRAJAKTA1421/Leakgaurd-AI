# 🛡️ LeakGuard AI
### Stop Hidden Subscriptions. Save More. Spend Smarter.

LeakGuard AI is an AI-powered financial assistant that helps users detect hidden subscriptions, recurring payment leaks, and unnecessary expenses before they silently drain their money.

Built for hackathons, LeakGuard AI analyzes bank transactions, identifies recurring payments, predicts forgotten subscriptions, and provides actionable insights to improve financial health.

---

## 🚀 Problem Statement

Millions of users lose money every month due to:

- Forgotten subscriptions
- Auto-renewing memberships
- Free trials converting into paid plans
- Duplicate recurring payments
- Hidden charges across multiple payment methods

Most banking applications only display transactions—they don't help users understand where their money is leaking.

---

## 💡 Solution

LeakGuard AI uses Artificial Intelligence to analyze transaction history and detect recurring payment leaks.

The platform automatically:

- Detects recurring subscriptions
- Predicts hidden payment leaks
- Identifies duplicate charges
- Calculates monthly and yearly spending
- Sends smart reminders before renewals
- Provides personalized saving recommendations

---

# ✨ Features

### 🔍 Hidden Subscription Detection
Automatically identifies active subscriptions from transaction history.

### 💳 Recurring Payment Tracker
Tracks monthly, quarterly, and yearly recurring payments.

### 🤖 AI Spending Insights
Provides intelligent spending analysis using AI.

### ⚠️ Renewal Alerts
Notifies users before subscriptions renew.

### 📊 Expense Dashboard
Visualizes spending with interactive charts and analytics.

### 💰 Saving Recommendations
Suggests subscriptions that users can cancel to save money.

### 📈 Monthly Financial Reports
Generates reports showing subscription trends and spending habits.

---

# 🧠 AI Workflow

1. User uploads bank statement or transaction history.
2. AI extracts transaction details.
3. Detects recurring payment patterns.
4. Identifies hidden subscriptions.
5. Calculates total subscription expenses.
6. Generates personalized savings insights.
7. Displays analytics dashboard.
